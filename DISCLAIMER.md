# Disklaimer

Repo **DikNom VM Windows 10 untuk Microsoft Office 2024** adalah dokumentasi
eksperimen dan skrip otomasi.
Repo ini bukan produk Microsoft dan tidak berafiliasi dengan Microsoft atau
NTDEV.

- **Windows** adalah milik Microsoft dan memerlukan lisensi yang sah.
- **Office 2024** adalah produk berlisensi; repo ini tidak menyediakan
  installer, product key, KMS, atau aktivator.
- **tiny10** adalah image Windows modifikasi pihak ketiga dari NTDEV, bukan
  ISO resmi Microsoft. Pengguna bertanggung jawab mematuhi lisensi dan
  ketentuan sumbernya.
- ISO Windows/tiny10 **tidak disimpan** di repo ini. Unduh dari sumber yang
  disebutkan di `docs/source-and-licenses.md`.
- Eksperimen RAM 2 GB berada di bawah minimum resmi Office 2024 (4 GB).
  "Bisa jalan" bukan berarti "didukung" atau "disarankan".
- tiny10 dapat menghilangkan komponen Windows dan dapat memiliki risiko
  keamanan/kompatibilitas. Gunakan untuk eksperimen, bukan data penting.
- Penulis tidak bertanggung jawab atas kehilangan data, masalah lisensi, atau
  kerusakan akibat penggunaan skrip ini.

Dengan menggunakan repo ini, kamu menyetujui bahwa kamu bertanggung jawab atas
lisensi, keamanan, dan data di mesinmu.
