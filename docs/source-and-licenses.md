# Sumber dan Lisensi

## tiny10

- tiny10 adalah image Windows 10 modifikasi pihak ketiga, bukan produk resmi
  Microsoft.
- Pembuat: **NTDEV**.
- Daftar resmi: https://ntdotdev.wordpress.com/2024/01/08/the-complete-tiny10-and-tiny11-list/
- Internet Archive: https://archive.org/details/tiny-10-NTDEV
- ISO yang diminta untuk eksperimen ini:
  https://archive.org/download/tiny-10-NTDEV/Tiny10%20B4%20x64.iso

Repo ini **tidak menyimpan ISO** dan tidak menjadikan GitHub sebagai mirror.
Pengguna harus mengunduh sendiri dari sumber di atas dan mematuhi ketentuan
sumber serta lisensi Microsoft.

## Microsoft Windows

- Windows adalah milik Microsoft.
- Gunakan lisensi Windows yang sah.
- tiny10 tidak menghilangkan kewajiban lisensi.
- ISO modifikasi tidak dapat diverifikasi dengan signature Microsoft; checksum
  hanya membuktikan file yang kamu unduh sama dengan yang diunduh, bukan
  menjamin keamanan atau legalitas.

## Microsoft Office

- Office 2024 adalah produk berlisensi.
- Repo ini tidak berisi installer, product key, KMS, atau aktivator.
- Office Deployment Tool diunduh resmi dari Microsoft.
- Contoh XML hanya konfigurasi; kamu tetap perlu lisensi.
- Jangan gunakan repo ini untuk menyebarkan produk bajakan.

Referensi resmi:

- Office 2024 FAQ:
  https://support.microsoft.com/en-us/office/lifecycle/office-2024-and-office-ltsc-2024-faq
- Office LTSC 2024 requirements:
  https://learn.microsoft.com/en-us/office/ltsc/2024/overview
- Office Deployment Tool:
  https://learn.microsoft.com/en-us/office/deploy-office/
